# Robert_Sosa_GoFundMe_Page

GoFundMe page for a hit and run car accident victim. Robert has gone thru 10 major surgeries. The accident broke his neck and his colon collapsed, leaving him with life threatening issues forever.

## Share page

This repository now includes a simple share page (`index.html`) that helps people share this fundraiser in a transparent, policy-compliant way:

- Copy the GoFundMe link quickly
- Share through the device native share dialog (if supported)
- Share with prefilled links for X, Facebook, WhatsApp, and email

Fundraiser link: `https://gofund.me/c3272ce87`

## Run locally

Open the file directly in your browser:

- `index.html`

or start a local static server from the repository root, for example:

```bash
python3 -m http.server
```
